      技能中心

      管理可在会话中复用的做法，保留每次改进。

      导入技能

      先在设置中连接本机 SkillNet。预览会固定提交、正文和许可指纹。确认后仅导入 SKILL.md，配套资源需另行补齐。

      自动发现 Codex、Claude、DSH、Agent Skills 等用户目录及目标项目中的技能库。按技能名和正文检查重复，只补充缺少的技能，保留配套文件。

      支持含 SKILL.md 的标准技能包；扫描不调用模型、不运行脚本。结果分为待导入、已有、同名冲突和无法读取，导入前可选择。不会自动覆盖已有技能。

      执行经验

      自动从验收、工具错误和用户纠正中发现线索。生成候选才调用模型；候选须独立验证，不会直接替换已启用技能。

      候选改进

      先隔离保存，再用冻结用例比较。候选不会自动进入聊天；失败、信息不足或未测出增益时保留原版本。

      机器检查的适用条件

      开始技能前逐项检查。目标按原文片段匹配，不满足或缺信息时暂停采用；通过只代表这些声明满足。

      对照测试

      实际产物验收（可选）

      声明项目相对路径和明确的文本或 JSON 判据。运行前冻结，完成时 SIH 重读实际文件；不满足时不能标记技能应用完成。条件需由你按任务目标核对。

      支持 text_contains / text_excludes（pointer 为空），json_equals（expected 为 JSON 字符串）、json_type、json_length。json_citations 检查 findings 数组中的引用，pointer 指向该数组、expected 为空。JSON Pointer 例如 /records/0/value，空字符串指整个文件对象。
