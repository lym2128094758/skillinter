# My Skill Library integration

Source https://github.com/lym2128094758/my-skill-library

Author lym2128094758

Revision e46acaddea051656cc96aed1ee80b69943a888b1

The user requested embedding this repository in Skillinter. The graph interface, 2D/3D renderers, view transitions, controls and D3 are copied from that revision. The SIH bridge serves local installed skills through the existing Node service and provides conversation actions and execution highlights. The upstream Python service and DSH launcher are replaced by this adapter.

D3 license and author notice are preserved in D3-LICENSE.txt. Upstream README states that no application license has been selected. This integration retains the author's attribution and records the source revision.
