# 公开数据快照

数据来自 UCI Machine Learning Repository，使用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。完整来源、获取日期、哈希、变换和标准答案见 `manifest.json`。红白酒按原 `color` 字段分表，单元格值保留。

数据及署名见各来源的 Citation 区域。 [Iris](https://archive.ics.uci.edu/dataset/53/iris)、[Wine](https://archive.ics.uci.edu/dataset/109/wine)、[Abalone](https://archive.ics.uci.edu/dataset/1/abalone)、[Glass Identification](https://archive.ics.uci.edu/dataset/42/glass+identification)、[Airfoil Self-Noise](https://archive.ics.uci.edu/dataset/291/airfoil+self-noise)、[Concrete Compressive Strength](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength)、[Wine Quality](https://archive.ics.uci.edu/dataset/186/wine+quality)、[Rice](https://archive.ics.uci.edu/dataset/545/rice+cammeo+and+osmancik)、[Raisin](https://archive.ics.uci.edu/dataset/850/raisin)。
