# 本轮审查入口

项目目标是让用户提供目标、材料和权限后，系统发现适用技能、按依赖执行、验证产物，并将执行经验转成隔离候选，经对照和审核后复用。总体架构及 A–F 开发顺序见 [架构任务书](architecture-roadmap.md)。

## 当前代码

已有技能身份和类型化关系、根预算与上下文管理、SkillNet 检索及公开发现、蒸馏与变异候选、只读 Worker 与项目记忆。具体实现分别见 [技能注册表](skill-registry.md)、[根预算](run-budget.md)、[SkillNet 适配](skillnet-engine.md) 和 [项目协作](project-collaboration.md)。

本次界面改动包括以下几项。

- 会话技能链默认显示本轮节点，按执行记录绘制依赖箭头并居中，保留全局切换。未安装的历史步骤显示为历史节点。
- 普通按钮采用固定图标及文字、上层玻璃按下变深并跟手的两层效果，位移上限 8 像素。切换滑块弹性上限 16 像素。
- 项目记忆支持默认草稿和手动保存，项目行操作保持单行。
- 删除页头模型标签，输入区继续选择模型。技能引擎模块加载失败时显示错误。

对应文件主要是 `web/app.js`、`web/style.css`、`web/skill-library/app.js`、`web/skill-library/liquid-controls.js` 及 `scripts/check-graph.mjs`。
