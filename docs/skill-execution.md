# 实际任务配对执行

入口：技能中心 → 候选改进 → 查看候选与验证 → **实际任务对照**。

1. 新建测试计划。系统带上同一技能已审核发布的实际用例，可以再添加最多 4 个新任务。合并后至少 2 个任务，最多 20 个，材料总量最多 2 MB。每个任务填写独立产物判据，可上传或手填 UTF-8 测试文件。缺失输入用例可以不提供文件。
2. 设置两组共用的模型调用次数、单组执行时间和单次输出 token 上限。默认建议 6 次 / 90 秒 / 4096 tokens，可在界面调整。
3. 点击“冻结此测试计划”。此步不调用模型，固定候选、原版本、材料、判据、资源指纹和执行实现指纹。修改材料须另建计划。
4. 点击“开始隔离执行”。每题两份独立临时工作目录，使用同一请求模型与预算；题间交替原技能 / 候选的执行先后。关闭页面不会隐式重新执行。
5. 页面按组显示真实文件检查、耗时、请求次数、服务商返回用量、模型响应与工具轨迹；产物可以分别下载，完整对照可导出 JSON。

## 执行边界

只复制用户提供的测试材料，**不会复制或挂载原项目树**。技能包支持最多 64 个普通资源、合计 1 MiB、单个 256 KB，资源在调用模型前冻结；拒绝链接和冻结期间变化的文件。两组各自复制冻结资源，不共享工作目录或对话历史。

使用主聊天的运行器与实际文件工具，但双重限制暴露和分发的工具：列目录、读文件、创建 / 局部修改文件、读取技能资源、更新计划、技能开始 / 结束和宿主产物验收。不能请求项目命令、网络检索、额外技能或内部模型工作流；模型编造的未开放调用返回固定错误。依赖命令或外部服务的技能不具备本对照环境的执行条件，不能算验证通过。

每组沿用该技能定义中的产物契约。测试任务的统一验收判据由宿主保管，模型上下文和工具响应只使用该组技能自身声明的条件。宿主在工具执行前冻结材料状态，执行后再用测试判据独立读取输出。必须有该方法实际参与的文件操作回执。技能的 `applied` 状态与外部产物检查分开保存。

## 结果

- `improved`：本套任务内候选全部通过、无回退，且至少一道任务由原组失败变为候选通过。
- `no_gain`：没有新增通过，不能称为技能提升。
- `failed`：候选仍有失败任务，或相对原组发生回退。
- `unknown`：执行未完成、方法未实际参与、模型身份未确认或其他证据不足。请求超时保留未知，不伪装成内容答错。

最新实际任务对照有新增通过且无回退时，可从候选详情核对计划和产物，再人工审核发布。已有实际试验时，最新实际结果决定能否提交审核。文本试验正在运行或有明确失败时也会阻止发布。发布前核对候选、基线、执行实现和配套资源指纹。试验编号与计划指纹随发布版本保存，指向当时的验收范围。

历史回归用例沿用首次收录时的材料、判据和发布来源。它们会随每次新计划重跑，恢复旧技能版本后也会保留。技能工坊要求最新实际对照中每项历史用例都通过，才允许发布候选。

在「经验」页打开一条工具或产物失败线索，点击「准备回归草稿」，选择同一项目的待发布候选。草稿会提取检查项和事件编号，测试指令、材料和预期值由操作者填写。勾选核对后冻结计划，计划会保存来源任务和事件引用。用例随实际任务对照审核发布后进入回归库。

两道手写任务属于功能验证，不能代表真实任务分布，也不证明因果贡献或通用收益。仅排除与已记录来源提示完全相同的任务、及与已记录输入字节指纹相同的材料；不能保证识别改写、近重复或模型预训练重叠。没有服务商用量时不虚构成本；API 思考强度记录在请求配置中，未声称控制模型随机性。

## 保存、停止与恢复

模型调用前，计划和本次试验写入 SQLite。每组完成即保存轨迹和产物字节，然后清理临时目录。停止、超时或模型错误保留部分组；服务重启不自动继续付费调用。新运行必须显式点击开始，沿用同一冻结计划并新增试验记录。

## 接口

本机同源访问，项目范围沿用技能中心的 `taskId / projectId`，GET 使用 `task / project` 查询参数。

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| POST | `/api/skill-studio/candidates/:id/execution-plans` | 提交 `{spec:{cases,budget}, taskId?, projectId?}`，冻结计划；201 返回快照。 |
| GET | 同上 | 返回该候选的计划与历史。 |
| GET | `/api/skill-studio/execution-plans/:id` | 读取计划、逐组结果、检查与产物元数据。 |
| POST | `/api/skill-studio/execution-plans/:id/run` | 使用当前会话或默认模型异步执行；202 返回 `planId / trialId`，之后轮询读取结果。 |
| POST | `/api/skill-studio/execution-plans/:id/stop` | 停止本进程管理的该计划，保留部分记录。 |
| GET | `/api/skill-studio/execution-plans/:id/trials/:trial/files/:file` | 在相同项目范围内下载已保存的实际产物，返回 SHA-256 头。 |

计划 JSON Schema 和工具范围见 [导出契约](tool-registry.json) 的 `conversation.skillExecution`。API 错误沿用应用 `{error:message}`：422 格式、重复、材料、路径或资源问题；404 不存在或范围不可见；409 版本变化、执行实现变化、候选已发布或已有模型任务。时间、时延、用量是 volatile，不能用它们要求逐字节重放。
