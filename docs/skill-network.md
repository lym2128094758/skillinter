# Skillinter 的技能网络闭环

目标：让科研或行业人员描述任务后，系统从已有方法中选择适合当前目标和材料的技能，按关系执行，留下可核对的产物与来源；把任务中的纠正和经验转为隔离候选，经对照检查和人工审核后形成可复用的新版本。

这条链路跨越主聊天与技能中心，不绑定某一种材料格式。

| 位置 | 实际作用 |
| --- | --- |
| 主聊天 | 接收任务、材料和中途引导；呈现计划、采用的技能、条件依据、执行回执与产物。 |
| 技能图谱 | 沿用原 SkillNet 球体；显示目录关系与实际采用路径。目录节点存在不代表本机可执行。 |
| 技能中心 / 技能 | 查看已安装方法、作用范围、历史版本和关联验证记录；用于下一次任务。 |
| 技能中心 / 创建 | 手动编写或从完成的对话与用户纠正起草方法，声明适用条件并设置检查用例。 |
| 技能中心 / 导入 | 扫描其他 Agent 的标准技能包，检查重复与冲突，保留资源文件，补充缺少的技能。 |
| 技能中心 / 候选改进 | 持久保存未启用的改进，查看冻结用例、两组实际输出、失败与重试；审核后发布新版本。 |
| 技能中心 / 经验 | 自动发现真实执行中的修复、失败及用户纠正线索；查看原始依据，生成隔离候选，并检查修改前后。 |
| 设置 | 连接模型 API、选择运行参数与管理归档。 |

## 当前可运行的闭环

1. **选择**：任务检索少量已安装方法。声明的目标片段、禁用片段、输入格式、项目材料和工具由宿主检查；允许空选、条件不足和拒绝。目标片段采用 NFKC 规范化后的文字匹配，没有语义泛化认证。
2. **编排与执行**：原目录依赖影响先后顺序，宿主工具执行实际读写；记录采用版本、材料指纹、计划修订和回执。权限由 Harness 管理，技能不能授予权限。
3. **经验提案**：宿主自动收集真实验收变化、重复工具错误和用户纠正，保留带序号的来源。用户选择线索后生成隔离候选，查看字段差异，再进入独立对照。保存候选不会写入正式技能文件，不会改变排序。见 [执行经验](skill-experiences.md)。
4. **冻结对照**：保存不可变的候选、基线版本、测试集与来源；保留原版本回归用例。每次验证固定同一请求模型，交替两组先后顺序，逐对保存输出、检查、用量和截断状态。来源提示的重复项只作回归，不计新增通过。
5. **审核发布**：候选须在冻结对照中新增通过且没有回退。已有实际任务试验时使用最新实际证据，否则使用文本对照。通过后由用户审核，发布版本固定对应的试验记录。可从历史恢复技能定义为新版本，后续聊天读取当前版本。

这借鉴了 SkillNet 的核心约束：**一次成功产生经验，不直接产生提升奖励；观察、候选、已验证范围和正式能力分别记录。**

## 验证的范围与后续工作

冻结文本对照的自动判据是“包含：”与“不包含：”。实际任务对照则在隔离目录执行受限文件工具，独立验收产物。两种验证均将结果限定在冻结用例的范围。手动发布用于导入和人工维护，版本详情标明验证来源。

技能版本现可声明执行前冻结的实际产物条件，宿主在技能结束与任务结束时独立重读验收；检查与输入指纹进入日志和候选来源。[产物验收范围](skill-delivery.md)

实际任务验收现已接入候选与原技能的隔离配对执行，支持冻结的自包含测试材料与有限文件工具，见 [实际任务对照](skill-execution.md)。

后续可为更复杂的产物增加独立参考算法，在积累可重复的对照结果后再验证个人能力网络的排序策略。

候选接口见 [候选契约](skill-candidates.md)。
